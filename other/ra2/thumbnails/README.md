# Steal a Dragon: 25 thumbnails

![All 25 thumbnails](_all_25.jpg)

Every file is **1920 × 1080 (16:9), JPG, under 0.7 MB**. That fits Roblox's experience thumbnails and the Ads
Manager image format. They were made with AI image generation, using real renders of the game (the dragon
models, the castle bases, the Dragon Road and the map) as references, so the dragons, castles and road match what
players see in the game.

## What the research says (and how these follow it)

| Recommendation | How these follow it |
|---|---|
| One clear focal point that reads at phone size (most Roblox players are on phones) | One big dragon or one character per image, big shapes |
| Bright, saturated colors and high contrast so it stands out in a grid of thumbnails | Blue skies, gold, red, rainbow; a dark one (#11) to stand out from the bright ones |
| Expressive characters and action | Running, shocked, sneaking and cheering faces |
| Text short (2–4 words), huge and outlined, or no text at all | 1–3 words with thick outlines; 3 have no text so you can test both |
| Show what the game really is; misleading thumbnails get clicks but lose players and get removed | Every scene is a real feature (see the table above) |
| Make each thumbnail clearly different, then let the data decide | 25 different hooks: stealing, rarity, friends, collecting, defending, events, funny |

## How to test them

Roblox tests thumbnails for you (**thumbnail personalization**): it shows different ones to different players and
picks the best one per player.

1. On the Creator Dashboard, open the experience and go to its thumbnail settings (under **Configure**). Upload
   **5** that are as different as possible, and turn on personalization if it isn't on. A good first set: **01, 06, 09, 03, 23**
   (stealing, event, friends, rarity, funny).
2. Leave them for at least **7 days**, then check the thumbnail results on the dashboard (click rate and play time
   per thumbnail).
3. Swap out the worst two for two new hooks from the list, and repeat.
4. Put the winner first. When you add a feature or event, make a new thumbnail for it.

For **Sponsored ads (Ads Manager)**, upload several images in one campaign (up to 10) and let Ads Manager split
the budget toward the best one.

## Getting ads approved quickly

Roblox reviews ad images (usually within about a day) and checks images separately when you upload them. The
common reasons for rejection, and how these thumbnails avoid them:

- [x] **No Roblox logo or trademarks.** None are shown.
- [x] **No Robux symbol, no "FREE", no prices or promises of rewards.** None. The coins in #14 are plain in-game
  coins with a star.
- [x] **No fake buttons or interface** (fake "Play" buttons, fake menus, fake prompts). None.
- [x] **No other games' characters or names**, and no real brands or real people. Only this game's own dragons,
  castles and blocky characters.
- [x] **No violence, blood, weapons or scary images.** The bonk is a cartoon star burst, and nobody gets hurt.
- [x] **Matches the game.** Every scene is a real feature. Keep that true: if you remove a feature (for example
  the Fire special), stop using its thumbnail.
- [x] **Readable, simple text** with no claims like "#1 game" or "best". "BE #1" invites the player to climb the
  leaderboard; it does not claim a ranking.
- [x] **Right size and format:** 1920 × 1080 JPG, well under the size limit.

**One honest risk:** the AI art is more polished and more detailed than the in-game models. Roblox allows stylised
key art, but a reviewer or a player could feel it oversells the look. To lower that risk:

- Run at least one image in each test that is close to the real game. **02**, **15** and **20** are the closest. You
  can also use the real screenshots in [`../screenshots`](../screenshots/README.md).
- If an ad is rejected for being misleading, resubmit with a real screenshot plus the same text.
- Watch the **play time** of players who arrived from each thumbnail, not only the click rate. A thumbnail with lots
  of clicks but short sessions is overselling.

If an image is rejected, the rejection email gives the reason. Change only that part and upload it as a new image.
Uploading the same image again is rejected again.

## Icon

These are **thumbnails** (16:9). The game **icon** is a separate 512 × 512 square. A good icon is a close-up of one
dragon's face (for example from #24 or #3), with no text, because icons show very small.
